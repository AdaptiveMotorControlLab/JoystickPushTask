# Ledex gap and stroke gauges (archived 17 Oct 2026)

STEP and STL for `gap_gauge_{0.5,1,2,3}mm` (shims for the plunger-to-washer gap, washer target rejected) and
`stroke_gauge_{2,3,4}mm` (forks on the boss end that set the plunger stroke). No longer generated by
`mechanical/ledex-holder-adjustable/make_ledex_holder.py`; set the stroke with calipers instead.
