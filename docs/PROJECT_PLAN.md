## Overview
Head-fixed mouse 1D forelimb object-push task, forked from the Mathis joystick-pull LabVIEW rig (Mathis et al. 2017). Trial: forepaw on a capacitive rest pad, then release and push a joystick-mounted object forward into a target band, then auditory cue, delay, spout extends, water. Optional later: axial resistance from a Ledex solenoid. Entry docs: `README.md`, `RIG_INVENTORY.md`, `MAGNET_COMMISSIONING.md`, `EVENTS_LOGGER_PLAN.md`, `parameters/README.md`.

## Task design
- Trial: forepaw on rest pad AND object in home → trial starts → push forward into target band (held for `end TO`) → immediate auditory cue (50 ms) → reward delay → spout extends → water → spout retracts. Overshoot is not an abort; leaving the band resets the dwell; trial ends at `move time`.
- Session blocks (later): Baseline (`mag=0`), Random perturbation, Fixed perturbation, Washout. Perturbation = axial resistance along the push axis (Ledex mounted on the home side, attraction opposes the push), pre-scripted `mag` per row, force magnitudes must be varied (proportional driver).
- Training progression (criterion on two consecutive days, change one thing at a time, ~3–6 weeks): 1) head-fix habituation with cue→water (short interval); 2) micro-push discovery; 3) proximal broad zone; 4) zone translation; 5) zone refinement; 6) delay 0/250/500/1000 ms; 7) expert stabilisation (≥80% success); 8) zero-force shadow sessions; 9) resistance pilot (separate mice), then main experiment. Optional rest-only stage as fallback.
- Parameter files: one identical-row file per stage in `parameters/training/` (27 columns; see `parameters/README.md`). Loader reads cases 0–26.
  Columns (0-based): 0,2 `home` push bounds (named X); 1,3 `home` lateral (named Y); 4 `home TO`; 5–8 legacy `start` box; 9 `start TO` (keep 0); 10,12 `end` push bounds; 11,13 `end` lateral; 14 `end TO`; 15 `mag`; 16 `magtime`; 17 `watertime` (130/185/240 ms → 4/6/8 µl); 18 `timeout` (Case 0 ITI); 19 `move time`; 20 `light` (0); 21 `reward delay`; 22 `cue duration`; 23 `spout extend`; 24 `spout settle`; 25 `consumption`; 26 `spout retract`. White/push values go in the columns named X; there is no ×2 on `home X2`. Do not reuse the old pull files' end voltages or `magtime=100`.
- Calibrate before final numbers: volts-to-mm (`calibration/joystick-volts-mm.md`), joystick noise, water volume (`calibration/water-volume.md`), spout settle, spring return.
- A fixed-spout 500 ms ITI with a 1.5 s consumption loop needs a rapid-success bench check (one cue and one water pulse per success).
- Perturbation notes: original Mathis kick was lateral at trial start; ours is sustained axial resistance. Minimal option `magtime ≈ move time`; cleaner is holding `mag` until a trial-end occurrence (Case 4 or Case 3 timeout) and a ~100 ms movement-onset delay. Do not reuse old `magtime=100` or the 2.2 V value; force-calibrate with a gauge/load cell and check heating.
- **Earlier plan (superseded by the Case 5 release clause above; kept for the replay numbers): start the trial (and `move time`) at pad release.** Use the existing Case 1 gate: Case 0 (pad + home held `home TO`, ITI elapsed) → Case 1 waits while the paw is on the pad; pad released AND object in the start box (= home box, `start TO` 0) → Case 2 (trial start, code 3, magnet occurrence); pad released but object out of the box → Case 0. ## VI architecture (`Push Behaviour_MCHALABI.vi` + `avg joystick and frame trig lick3.vi`, `frame counter.vi`, `PushTask Globals.vi`)
- State machine in the middle While loop (state in a shift register, initial 0): Case 0 gate (object in home ROI AND rest pad `ai2` > threshold, held `home TO`, AND `timeout` elapsed), Case 1 start ROI, Case 2 stamp trial start and set the magnet occurrence, Case 3 movement window (timeout → Case 0; end ROI held `end TO` → Case 4), Case 4 set the reward occurrence.
- Water loop (occurrence-driven flat sequence): cue HIGH → cue wait → cue LOW → reward delay → spout extend → settle → water HIGH → `watertime` → water LOW → consumption → spout retract.
- Magnet loop: occurrence → AO0 `mag` for `magtime` (plus laser counter pulse, keyed off) → reset 0.
- Startup writes cue LOW, water LOW, magnet 0 V, spout to `Session start spout (V)`; normal Stop propagates through `stop all`; Stop tests from idle, reward delay and extended spout passed.
- Rest-pad threshold control and `paw on rest pad` Boolean sit before the `home TO` hold. Home gate and rest pad share one timer; ROI X-in-range AND Y-in-range per row.
- Known: `Trial #` is incremented at trial start (magnet loop) but indexed at success (water loop); verify alignment. The magnet loop can miss a trial-start occurrence (zuchon 16 Oct, once, after a 328 s pause), which also drops a TRIAL row.
